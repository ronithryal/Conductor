# Conductor — 3-Day Demo Prototype: Locked Implementation Plan

> Generated by /autoplan | 2026-04-23 | Status: PENDING APPROVAL
> Single-reviewer mode (Codex CLI unavailable)

---

## Sprint Objective

Build a polished, browser-based prototype of Conductor for a 60-90 second YC/a16z demo video.
Prove the interface thesis: visual agent orchestration is 10x better than terminals and config files.
No real model calls. No auth. No production infrastructure.

---

## Approved Scope

### Build:
- Infinite pannable/zoomable canvas (React Flow, custom styled)
- Custom node cards: Agent, Tool, Trigger
- Typed connection edges with hover payload preview
- Agent Inspector right panel (model dropdown, system prompt, tools, cost estimator)
- 3 seeded templates with one-click install
- Live run feed with SSE-driven simulation
- Node status animation through states (idle → queued → running → success/error)
- Scripted failure + retry flow (Research Agent timeout)
- Observability Dashboard tab (KPIs, 7-day chart, recent runs table)
- Fake collaboration (avatar stack, activity feed, one comment pin)

### Cut (confirmed):
Auth, real model API calls, BullMQ, Redis, Postgres, S3, Firecracker microVMs,
Tauri, Clerk SSO, marketplace publishing, RBAC, billing, real MCP, real tool execution.

```typescript
export type NodeStatus = 'idle' | 'queued' | 'running' | 'success' | 'error'
export type ModelOption =
  | 'claude-sonnet-4'

  | 'gpt-4o'
  | 'o3'
  | 'gemini-2-flash'
  | 'ollama-llama3'
export type ConnectionType = 'trigger' | 'data' | 'approval' | 'fallback'

export interface AgentNodeData {
  name: string
  model: ModelOption
  status: NodeStatus
  systemPrompt: string
  tools: string[]
  estimatedCost: string
  lastRunAt?: string
  retryCount: number
}

export interface ToolNodeData {
  name: string
  category: 'web' | 'files' | 'api' | 'database' | 'comms'
  status: NodeStatus
}

export interface TriggerNodeData {
  label: string
  triggerType: 'manual' | 'schedule' | 'webhook' | 'event'
  schedule?: string
}

export interface TypedEdgeData {
  connectionType: ConnectionType
  payloadPreview: string
  lastTransmit?: string
}
```

### types/runs.ts
```typescript
export type RunPhase = 'idle' | 'queued' | 'running' | 'success' | 'error'

export interface RunEvent {
  id: string
  nodeId: string
  nodeName: string
  type: 'queued' | 'node-started' | 'tool-call' | 'step' | 'completed' | 'failed' | 'run-complete' | 'run-failed'
  message: string
  toolName?: string
  toolInput?: string
  output?: string
  elapsed: number       // ms since run started
  timestamp: number
}
```

### types/events.ts (API)
```typescript
export type SSEEventType =
  | 'run.queued'
  | 'run.node.started'
  | 'run.node.tool-call'
  | 'run.node.step'
  | 'run.node.completed'
  | 'run.node.failed'
  | 'run.completed'
  | 'run.failed'

export interface SSEEvent {
  id: string
  type: SSEEventType
  timestamp: number
  payload: {
    nodeId: string
    nodeName: string
    message: string
    toolName?: string
    toolInput?: string
    toolOutput?: string
    elapsed: number
    errorCode?: 'TIMEOUT' | 'TOOL_ERROR' | 'MODEL_ERROR' | 'RATE_LIMIT'
    retryCount?: number
  }
}
```

| Failure/retry slips to Day 3 | Medium | Medium | It's the Day 2 stretch goal by design |
